# iPhone User Guide assistant

This is a retrieval-augmented chatbot that answers questions **strictly** from the
Apple iPhone User Guide (iOS 7.1).

- Answers are grounded only in the guide's contents — no outside knowledge.
- Every answer cites the page (and section) it came from.
- If the answer isn't in the guide, the bot says so instead of guessing.
- It remembers earlier questions within a session, so follow-ups work.

Try: *"How do I set up Do Not Disturb?"* or *"How do I take a panorama photo?"*
